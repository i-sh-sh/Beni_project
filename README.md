## מה עדיין חסר כדי לעלות לאוויר

### 1. פרטי קשר — קובץ `assets/js/site.config.js`

כל הפרטים במקום אחד. כל שדה שנשאר ריק מסומן אוטומטית באתר בצהוב,
והכפתור שתלוי בו מפנה לטופס יצירת הקשר במקום להישאר קישור שבור.

| שדה | מה למלא |
|---|---|
| `siteUrl` | כתובת האתר המלאה, למשל `https://www.beni-retail.co.il` |
| `whatsappNumber` | מספר וואטסאפ בינלאומי ללא `+`, למשל `972520000000` |
| `email` | כתובת דוא״ל |
| `serviceAreas` | אזורי הפעילות כטקסט, למשל `ירושלים, בית שמש והסביבה` |
| `serviceAreaList` | אותם אזורים כרשימה, עבור מנועי חיפוש |
| `formEndpoint` | כתובת לקבלת הטופס (ראו סעיף 4) |
| `introOfferText` | הצעת הפתיחה, למשל `שיחת אבחון 20 דקות, ללא עלות` |
| `priceRangeText` | טווח מחיר לסקירת חנות |
| `showTestimonials` | **להעביר ל־`true` רק אחרי שהוזנו המלצות אמיתיות** |
| `googleAnalyticsId` | מזהה GA4, למשל `G-XXXXXXXXXX` |
| `metaPixelId` | מזהה Meta Pixel — להשאיר ריק כל עוד אין קמפיין פעיל |
| `showAdminNotices` | **להעביר ל־`false` לפני הפרסום** — מסתיר את ההערות הצהובות |

### 2. הדומיין — בוצע

הכתובת `https://www.pop-style.design` מוגדרת ב־`index.html` (canonical,
og:url, og:image, twitter:image), ב־`sitemap.xml`, ב־`robots.txt`
וב־`assets/js/site.config.js`. ההתראה הצהובה על הדומיין נכבית מאליה.

**נותר:** לוודא שהאתר מוגש מהכתובת הזו ב־HTTPS, ולהריץ שוב
`node tools/og/build-og.mjs` אם שפת העיצוב תשתנה.

### 5. חיבור הטופס

הטופס מבצע ולידציה מלאה בצד הלקוח. **כל עוד `formEndpoint` ריק, הטופס אינו
מציג הודעת הצלחה** — הוא מודיע במפורש ששליחה אינה זמינה ומפנה לוואטסאפ או
לטלפון, ושומר את מה שהוקלד. הבחירה הזו מכוונת: הודעת "תודה, הפרטים התקבלו"
כשאיש לא קיבל אותם גורמת לאובדן לידים שקט שאיש לא ידע עליו.

הטופס שולח `POST` עם `Content-Type: application/json` ומצפה לתשובה תקינה
(`2xx`). מתאים לכל שירות טפסים (Formspree, Web3Forms), ל־Webhook של CRM,
או ל־endpoint עצמאי. מבנה הנתונים:

```json
{
  "fullname": "...", "business": "...", "storetype": "...",
  "city": "...", "phone": "...", "message": "...",
  "source": "אתר תדמית — טופס יצירת קשר",
  "submittedAt": "2026-01-01T00:00:00.000Z"
}
```

**לבדוק אחרי החיבור:** לשלוח פנייה אמיתית ולוודא שהיא הגיעה ליעד. פעמיים.

## כיוון העיצוב — "הדוח"

החלטת מועצה **0009**. העולם: **סרט הקופה — דוח ה-Z** שכל בעל חנות בישראל
קורא בסוף היום, והמסמך היחיד שאומר לו מה היום באמת עשה. זהו החפץ שקהל
היעד של העמוד מחזיק ביד כל ערב.

העמוד הוא **רצועת נייר מנוקבת אחת על קרקע כחולה מוצפת**. אין כותרת
דביקה ואין תפריט נפתח: הניווט הוא תוכן העניינים של המסמך, והקריאה
לפעולה שנשארת על המסך היא הספח שנתלש מתחתיתו.

הכיוון הקודם (השדה הכחול, 0004) שירת היטב, והלוגו, הפלטה והגופנים שלו
עוברים לכאן ללא שינוי. מה שהוחלף הוא שפת הצורה בלבד — **אפס מילים של
תוכן נכתבו, נמחקו או קוצרו במעבר.**

**מה מרכיב את השפה**

| רכיב | ערך | נימוק |
|---|---|---|
| קרקע | `#0088FF`, הכחול הרשמי | אסטרטגיית Committed: הכחול מציף ונושא כ-55% מהמשטח |
| רצועה | לבן `#ffffff`, עד 760px | הנייר. הלבן הוא צבע ההקלה היחיד |
| דיו | `#111827` | בלוק המוצר המוביל ובלוק ההיפוך בכותרת |
| כותרות | Rubik 800 | גופן התצוגה של חבילת המיתוג |
| גוף | Assistant | קריא לטקסט רץ |
| המכשיר המרכזי | שורת מסמך: תווית · מוביל נקודות · ערך | חוזר בסיכום, בעובדות, בפרטי הקשר ובתוכן העניינים |
| מבנה | קווי עמודה וקווי סיכום | **אין בעמוד אף קו דקורטיבי** |
| צילומים | סימני מדידה כחולים | המסגרת מסמנת את מה שחשוב, הנושא נשאר גלוי לגמרי תחתיה |

**שלוש מלכודות שנפתרו, ואין לחזור אליהן**

1. **אין טקסט רץ על הכחול.** לבן קטן על `#0088FF` נותן 3.52:1 ונכשל.
   הכחול נושא תצוגה וקרקע בלבד; כל טקסט יושב על הרצועה או על הדיו.
   שלושת הצמדים האסורים מאומתים כאסורים ב-`tools/contrast.mjs`.
2. **אין ריווח אותיות על עברית, ואין `direction: ltr` על אלמנט בלוקי.**
   הראשון שובר מילים; השני הופך את יישור הבלוק כולו. מספרים לטיניים
   בתוך עברית מקבלים `<bdi dir="ltr">`, ופסאודו דו־כיווני מקבל
   `unicode-bidi: isolate`.
3. **אין תוכן שמוסתר בהמתנה ל-JavaScript.** החשיפה בגלילה מתחילה
   ממצב שכבר נראה (`opacity: .48`) ומתמלאת. `clip-path` שמסתיר שורה
   לחלוטין נוסה, נמדד ונזרק.

**מספור הסעיפים נספר ב-CSS.** אזור ההמלצות מוסתר עד שיהיו ממליצים
אמיתיים; מונה CSS אינו סופר אלמנט עם `display: none`, ולכן הרצף נכון
גם כשהוא חסר — ותוכן העניינים נשאר מסונכרן איתו, עם JavaScript ובלעדיו.

  טקסט גוף על הרצועה: 17.74:1. התווית החלשה ביותר: 4.57:1.
- כל שדות הטופס עם `<label>` מקושר, שגיאות עם `role="alert"` ליד השדה.
- כל יעדי הנגיעה עומדים ב-WCAG 2.2 · 2.5.8 (24px), ונבדקים בשער.
- ניווט מקלדת מלא, מצבי מיקוד גלויים, קישור "דילוג לתוכן".
- `prefers-reduced-motion` מכובד — האנימציות מבוטלות לחלוטין.
- ללא אמוג׳י כאייקונים; כל האייקונים הם SVG מוטמע.
- **האתר עובד גם ללא JavaScript** — כל התוכן מוצג, רק אפקט החשיפה מושבת.
  אזור ההמלצות מוסתר כברירת מחדל ב־HTML עצמו, כך שגם ללא JavaScript
  לא מוצגים כרטיסים ריקים.

## בדיקות שבוצעו

נבדק בדפדפן Chromium אמיתי, בכל העמודים:

- ללא גלישה אופקית ברוחבים 375 / 414 / 768 / 1024 / 1440 פיקסלים.
- ללא שגיאות JavaScript וללא בקשות רשת שנכשלו.
- אין קישורים שבורים; כל עוגן מצביע לאזור קיים.
- הגופנים המקומיים נטענים בפועל (`document.fonts.check`).
- ולידציית הטופס: שליחה ריקה, טלפון שגוי, ומסלול מלא.
- טופס ללא `formEndpoint`: מציג כשל, שומר את השדות, ואינו מדווח המרה.
- מלכודת הבוטים ומלכודת הזמן חוסמות שליחה.
- באנר ההסכמה: אין בקשת רשת אחת לכלי מדידה לפני אישור; בחירה נשמרת;
  "רק ההכרחי" מונע טעינה גם אחרי רענון.
- אזור ההמלצות מוסתר ללא JavaScript ונחשף כאשר `showTestimonials` דלוק.
- תוכן העניינים: הספרות תואמות את הסעיפים, עם JavaScript ובלעדיו.
- קישור "דילוג לתוכן" הוא תחנת ה־Tab הראשונה.
- `prefers-reduced-motion`: אין תוכן שנשאר מוסתר.

## מצב התצוגה — כבוי להצגה ללקוח

`showAdminNotices` ב-`assets/js/site.config.js` הועבר ל-**false** כדי שאפשר
יהיה להציג את העמוד לבני. המשמעות:

- שלוש הערות המנהל הצהובות אינן מוצגות (הן עדיין ב-HTML, עם ההסבר שלהן).
- מילויי־המקום מאבדים את תיבת הענבר המקווקוות ונשארים טקסט אפור שקט.
- הפעולות שחסרים להן פרטי קשר אינן מסומנות במסגרת מקווקוות — הן עדיין
  נופלות לטופס יצירת הקשר, כמתוכנן.

**מה עדיין טעון אישור, ולא נעלם רק כי ההערה הוסתרה:**

| מה | היכן | מצב |
|---|---|---|
| תכולת מוצר 2 (רשת חנויות) | `index.html`, `.service` השני | הסעיפים הוצעו על בסיס התהליך של מוצר 1. **יש לאשר או לתקן מול בני.** |
| המלצות לקוחות | `showTestimonials: false` | להפעיל רק עם אישור בכתב מבעלי החנויות |
| פרטי קשר | `site.config.js` | טלפון, וואטסאפ, דוא״ל, אזורי שירות, `formEndpoint` — כולם ריקים |

להחזרת מצב העריכה: `showAdminNotices: true`.

## שיחה ישירה — הוסרה

4.11.2026: אפשרות ההתקשרות הישירה הוסרה מהאתר לבקשת בעל הפרויקט.
ערוצי הפנייה הם **וואטסאפ, דוא"ל וטופס יצירת הקשר** בלבד.

מה ירד, ומה צריך לחזור יחד אם אי פעם מחזירים את זה:

| מה | היכן |
|---|---|
| כפתור "התקשרו עכשיו" | אזור יצירת הקשר |
| כפתור "להתקשר" | הספח במובייל — נשאר כפתור וואטסאפ יחיד ברוחב מלא |
| שורת הטלפון | שורות פרטי הקשר |
| `tel:` בנוסח הנפילה של הטופס | `main.js`, `alternativeChannels` |
| `telephone` ב-JSON-LD | `schema.js` — בלעדיו גוגל לא מציג כפתור חיוג בתוצאות |
| `phoneDial` / `phoneDisplay` | `site.config.js` |
| האירוע `contact_phone` | מעקב ההמרות |

**שדה הטלפון בטופס נשאר** — הוא קולט את המספר של הפונה, וזה ההפך.
