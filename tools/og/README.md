# נכס השיתוף (OG)

התמונה שוואטסאפ ופייסבוק מציגים כשמשתפים קישור לאתר.
**זהו המסך הראשון שהקהל רואה** — לפני ההירו — ולכן היא נבנית מאותם
טוקנים וגופנים של האתר ולא כקובץ ידני נפרד.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `og.html` | התבנית. טוענת את `assets/css/style.css` ומשתמשת בטוקני `--plan-*` |
| `build-og.mjs` | מרנדר את התבנית ל־`assets/img/og-image.png` בגודל 1200×630 |

## מתי להריץ

רק כששפת העיצוב או הניסוח משתנים. התמונה עצמה נשמרת ב־git,
כך שהאתר אינו דורש שלב בנייה.

```bash
npm install playwright-core      # כלי פיתוח בלבד — האתר עצמו ללא תלויות
node tools/og/build-og.mjs
```

אם Chromium מותקן במקום לא סטנדרטי:

```bash
CHROMIUM_PATH=/path/to/chrome node tools/og/build-og.mjs
```

## אחרי הרצה

לוודא שהכתובת ב־`og:image` ב־`index.html` מצביעה לדומיין האמיתי —
וואטסאפ ופייסבוק קוראים את התגית בלי להריץ JavaScript, ולכן כתובת
יחסית או דומיין לדוגמה שוברים את התצוגה המקדימה.
